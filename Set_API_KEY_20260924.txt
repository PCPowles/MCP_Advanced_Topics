💻 macOS & Linux
Most modern Macs use Zsh, while Linux usually defaults to Bash.
Temporary (Resets when you close the terminal)
Run this command directly in your terminal: 
bash
export YOUR_API_KEY_NAME="your_actual_key_here"
Use code with caution.
Permanent (Persists across restarts)
To save it so you don't have to re-enter it every time, add it to your shell profile configuration file: 

OpenAI Developers
 +1
For Zsh (Default macOS):
bash
echo 'export YOUR_API_KEY_NAME="your_actual_key_here"' >> ~/.zshrc
source ~/.zshrc
Use code with caution.
For Bash (Default Linux):
bash
echo 'export YOUR_API_KEY_NAME="your_actual_key_here"' >> ~/.bashrc
source ~/.bashrc
Use code with caution.
🪟 Windows
Choose the method based on which terminal tool you are actively using. 

www.anaconda.com
PowerShell
Temporary:
powershell
$env:YOUR_API_KEY_NAME="your_actual_key_here"
Use code with caution.
Permanent:
powershell
[System.Environment]::SetEnvironmentVariable('YOUR_API_KEY_NAME', 'your_actual_key_here', 'User')
Use code with caution.
(Note: You will need to restart your PowerShell window for the permanent change to apply).

Command Prompt (CMD)
Temporary:
cmd

Permanent:
cmd
setx YOUR_API_KEY_NAME "your_actual_key_here"

🔍 How to Verify It Worked
To check if the terminal successfully registered your variable, print its value:

If it prints your key back to you, you are ready to go!
